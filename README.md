# 🤖 IntelliBot AI Assistant

## Advanced Rule-Based AI Chatbot

IntelliBot is a professional Rule-Based AI Chatbot developed as part of the **Decode Labs Artificial Intelligence Internship Program**. The chatbot uses predefined rules, decision-making logic, input sanitization, and dictionary-based intent matching to simulate intelligent conversations with users.

Unlike a basic chatbot, IntelliBot provides additional capabilities such as user memory, mood detection, calculator support, motivational quotes, jokes, chat history tracking, personality modes, and a modern Streamlit-based dashboard.

---

## 📌 Project Overview

The objective of this project is to understand the fundamentals of conversational AI by implementing a rule-based chatbot that can interact with users through predefined intents and responses.

The chatbot processes user input, identifies user intent, executes the corresponding logic, and generates appropriate responses. The project demonstrates core Artificial Intelligence concepts such as:

* Input Processing
* Decision Making
* Rule-Based Systems
* Intent Matching
* Conversational Interfaces
* Human-Computer Interaction

## ⚙️ Installation Guide

### Step 1: Clone Repository

```bash
git clone https://github.com/Bommana-suchitra/Decodelabs-Task-1-Bommana-Suchitra.git
```

### Step 2: Navigate to Project Folder

```bash
cd DECODE-LABS-P1-CHATBOT
```

### Step 3: Create Virtual Environment

```bash
python -m venv venv
```

### Step 4: Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### PowerShell

```powershell
.\venv\Scripts\Activate.ps1
```

### Step 5: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 6: Run Application

```bash
streamlit run app.py
```

### Step 7: Open Browser

```text
http://localhost:8501
```
